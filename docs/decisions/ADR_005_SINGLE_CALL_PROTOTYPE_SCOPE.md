# ADR 005: Single-Call Prototype Scope

## Status

Accepted

## Context

The immediate objective is a reliable feasibility demo, not production infrastructure rollout.

## Decision

The current goal is a reliable single-call feasibility prototype, not production infra. Optimize for demo stability, observability, and correctness before scale.

## Consequences

This focuses team effort and lowers risk, while deferring multi-call scale capabilities.
