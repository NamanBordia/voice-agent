# Historical telephony architecture

Exotel support has been removed from the active application by
[ADR-006](decisions/ADR_006_BROWSER_LOCAL_FILES.md).

The active interface is the local browser. There is no telephone webhook, media WebSocket,
outbound dialing, ngrok requirement, or Exotel credential configuration.

See [ARCHITECTURE](ARCHITECTURE.md) and [RUNBOOK](RUNBOOK.md) for current behavior.
